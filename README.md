# Hinglaj Auto Care — Official Production Website

A clean, modern, production-ready website built for **Hinglaj Auto Care**, a premier car repair and maintenance garage in Ahmedabad, Gujarat, India.

Built strictly according to agency standards: warm off-white canvas, royal purple brand identity, crimson red accents, Barlow typography, mobile-first responsive layout, and direct one-click WhatsApp & phone integration.

## 🎨 Brand Identity

Sampled directly from the official workshop signboard:
- **Primary Purple (`#482F6E`)**: Brand wordmark "HINGLAJ" & aerodynamic lower contour.
- **Secondary Speed Red (`#C8324C`)**: Upper sports car roofline silhouette, "AUTO CARE" mark & action CTAs.
- **Warm Canvas Background (`#FAF9F6`)**: Clean, editorial white/cream backdrop for maximum contrast and readability.
- **Deep Plum Ink (`#171320`)**: Reserved for dark sections (top bar, hero overlay, and footer).

## ⚡ Key Highlights

- **Zero Framework Bloat**: Pure semantic HTML5, modern CSS3, and vanilla JS. Instant load times, zero build steps, zero dependencies.
- **Local Conversion Focused**: Every section is designed to build trust for vehicle owners in Ahmedabad: transparent upfront estimates, 13 core car service categories, 4-step repair process, 5.0 Google review rating, and instant WhatsApp booking.
- **Real High-Resolution Photography**: Complete suite of real automotive workshop images optimized for web speed with an interactive keyboard-accessible lightbox modal.
- **Precise Location & Navigation**: Pinned Google Maps embed and one-tap turn-by-turn directions to Aashirwad Complex, Chanakyapuri Road, Ahmedabad.
- **Mobile-First Experience**: Persistent mobile bottom sticky bar with direct "Call" and "WhatsApp" buttons.
